# news_agent_v2

Консольный агент: отвечает на вопросы про ИИ, ML и кибербезопасность. Находит статьи Хабра по смыслу вопроса и для каждой подбирает первоисточник (arXiv, BAIR, Google Research и др.).

Процедурный код, без классов. Модель и эмбеддинги работают локально через Ollama.

## Как это работает

```
вопрос → Qwen решает, какой инструмент вызвать
           │
           ├─ tool_time()            → дата и время
           ├─ tool_news(topic)       → RSS Хабра → коллекция habr_news
           └─ tool_search_news(q)
                 1. коллекции пусты? → догружает Хабр и первоисточники
                 2. вопрос → эмбеддинг → CANDIDATES статей Хабра по смыслу
                 3. для каждой статьи → ближайшая запись первоисточника
                 4. сортировка по сходству → топ-3 со ссылками
```

Две коллекции Chroma (метрика cosine, живут в памяти):

| Коллекция | Что хранит |
|---|---|
| `habr_news` | статьи Хабра (заголовок + RSS-описание) |
| `primary_news` | записи лент из `SOURCES["primary"]` |

`tool_search_news` возвращает JSON: `title`, `link`, `primary_source`, `primary_title`, `primary_link`, `similarity`. `similarity = 1 - cosine distance`, чем ближе к 1, тем ближе по смыслу.

## Файлы

| Файл | Назначение |
|---|---|
| `news_agent_v2.py` | агент: инструменты, коллекции, цикл диалога |
| `sources.py` | словари RSS-лент, `load_primary`, `entries_to_items`, `clean_html` |
| `system_message.txt` | системный промпт (читается при запуске) |

## Установка

Нужен Python 3.10+ и запущенный [Ollama](https://ollama.com).

```bash
ollama pull qwen2.5:7b
ollama pull bge-m3

pip install requests feedparser pydantic chromadb beautifulsoup4
```

Логика Chroma проверялась на `chromadb` 1.5.9. Параметр `configuration={"hnsw": ...}` нужен свежей версии.

## Запуск

```bash
# 1. (по желанию) диагностика лент первоисточников
python sources.py

# 2. агент
python news_agent_v2.py
```

Выход: `exit` или `выход`.

Примеры вопросов:
- «Какие есть исследования по гибридным архитектурам ИИ?» → `tool_search_news`
- «Покажи свежие новости по кибербезопасности» → `tool_news`
- «Который час?» → `tool_time`

Первый поиск медленный: агент скачивает ленты и считает эмбеддинги. Повторные поиски в том же запуске быстрее, потому что уже сохранённые записи не пересчитываются.

## Настройки (`news_agent_v2.py`)

| Константа | Значение | Что делает |
|---|---|---|
| `CHAT_MODEL` | `qwen2.5:7b` | модель диалога |
| `EMBED_MODEL` | `bge-m3:latest` | модель эмбеддингов (многоязычная: русский Хабр и английский arXiv) |
| `MAX_TURNS` | 10 | сколько последних вопросов хранить в истории |
| `MAX_STEPS` | 4 | максимум раундов вызова инструментов на один вопрос |
| `CANDIDATES` | 10 | сколько статей Хабра берём по смыслу вопроса, прежде чем искать им первоисточник. `3` даёт просто топ-3 по вопросу |
| `TIMEOUT` | 90 | таймаут запросов к Ollama и RSS, сек |

Лимит записей на каждую ленту первоисточников: `load_primary(limit=30)` в `sources.py`.

## Известные ограничения

- **arXiv по выходным.** По спецификации arXiv RSS-ленты пусты в субботу и воскресенье и в праздничные дни. Остальные первоисточники при этом работают.
- **Коллекции в памяти.** При каждом запуске всё скачивается и считается заново. Для сохранения между запусками можно заменить `chromadb.Client()` на `chromadb.PersistentClient(path=...)`.
- **Тексты.** В поиске участвуют только заголовок и RSS-описание, не полные тексты статей.
- **Не реализовано:** late chunking, семантическая дедупликация, оценка надёжности источников, полные тексты статей.
- **Qwen 7B** может ошибаться в выборе инструмента или пропускать ссылки. Помогает чёткий `system_message.txt`.
- Код проверялся на заглушках вместо Ollama и интернета. Работа с настоящими Ollama, Хабром и лентами первоисточников отдельно не проверялась.

## Если что-то не работает

| Симптом | Что смотреть |
|---|---|
| `Connection error [u]` | запущен ли Ollama (`ollama serve`) и скачаны ли обе модели |
| `Не удалось загрузить статьи или первоисточники.` | доступность Хабра и лент; `python sources.py` покажет число записей по каждой ленте |
| `[primary] имя: 0 записей` | пустая лента (выходные у arXiv) или недоступный адрес; смотри `bozo` в выводе |
| Модель не вызывает инструменты | проверь `system_message.txt` и что модель поддерживает tool calling |
